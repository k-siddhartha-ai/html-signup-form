# HTML Sign-Up Form

A beginner-friendly **Sign-Up Form project built using HTML5 and CSS3**, demonstrating different HTML form elements, input types, multimedia integration, and form submission.

🔗 **Live Demo:** https://signup-form-chi-bice.vercel.app/

## 📌 Project Overview

This project demonstrates how to create a sign-up form using HTML5 form elements and CSS styling. It includes various input types that allow users to enter personal information, select options, upload a file, and submit the form.

The project also integrates audio, video, images, and an embedded YouTube video.

## ✨ Features

- User name input field
- Email input with required validation
- Password input field
- Date of birth selection
- Gender selection using radio buttons
- Mobile number input
- Language selection using checkboxes
- Time and date-time input fields
- Rating selection using a range slider
- URL input field
- Resume file selection
- Address text area
- Reset and search input fields
- Color picker
- Submit button with a success page
- Audio player integration
- Image and video element demonstration
- Embedded YouTube video
- CSS styling with a background image, borders, rounded corners, and box shadow

## 🛠️ Technologies Used

- **HTML5** – Structure and form elements
- **CSS3** – Styling and layout
- **JavaScript** – Not used in this project
- **Vercel** – Deployment and hosting
- **GitHub** – Source code management

## ⚙️ How to Run Locally

1. Clone this repository:

```bash
git clone https://github.com/k-siddhartha-ai/html-signup-form.git
```

2. Open the project folder:

```bash
cd html-signup-form
```

3. Open `index.html` in your browser.

No additional installation or build tools are required.

## ⚠️ Project Limitations

This is a front-end demonstration project.

- Form submissions redirect to a success page.
- User registration details are not stored in a database.
- No backend or authentication system is implemented.
- The video element currently has no playable video source.
